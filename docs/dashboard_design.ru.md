# Дизайн дашборда: что я сделала и почему

[English version](dashboard_design.md)

Цифры и логика дашборда берутся из SQL в `sql/dashboard/` и определений в
[dashboard_spec.ru.md](dashboard_spec.ru.md). Эта заметка только о том, как страница
выглядит и читается. Каждый принцип ниже применён в `src/pa/dashboard.py`.

| Принцип | Что делает страница | Зачем |
|---|---|---|
| Заголовок говорит вывод | Заголовок страницы и каждого блока это предложение с цифрами («Weekly orders grew from about 270 to about 1,370, with one spike: ...»). Они пишутся в коде из результатов запросов, поэтому не разойдутся с данными. | Читатель получает мысль, не расшифровывая график; подпись «Orders per week» оставляет эту работу ему. |
| Одна строка «что это значит» | Под заголовком: в июне 2018 была самая низкая доля опозданий в окне, поэтому рост в июле выглядит больше, чем есть. | Карточка скажет «+2,2 п.п., плохо»; контекст скажет, что это не тревожно. Цифра без контекста вводит в заблуждение. |
| Аннотации прямо на графике | Неделя Чёрной пятницы подписана на графике; серая полоса в конце говорит, что данные редеют в августе 2018 и не рисуются; последнее значение стоит у конца линии вместо легенды. | Прямые подписи убирают поиск соответствия между легендой и линией. |
| Серый для фона, один акцент | Серый для всего контекста, один глубокий бирюзовый для важного (текущий период, самое большое падение воронки, линия тренда). | Когда цветное всё, не выделяется ничего. |
| Читается и без различения цветов | Хорошо = бирюзовый, плохо = оранжевый (разный оттенок; светлота текста почти одинакова), и у каждого изменения ещё стрелка и знак (▲ +2.2 pp). В таблицах подкрашены только ячейки опозданий и оценки, мягко. | Пары красный/зелёный недостаточно для заметной доли мужчин (красно-зелёная слепота распространена); смысл не должен держаться только на цвете. |
| Меньше лишнего | Без рамок, теней и градиентов у карточек; без панели и логотипа Plotly; без вертикальной сетки, очень светлая горизонтальная, без линий осей, прозрачный фон графика, малые поля. | Каждый пиксель, который не данные и не подпись, соревнуется с данными. |
| Чистая подсказка | Единая подсказка на графике динамики с отформатированными числами, белая плашка, без рамок трасс. | Подсказка нужна для точных значений, поэтому показывает только их. |
| Спарклайны в карточках | Линия за 12 месяцев без осей под каждой карточкой, последняя точка в цвете акцента. | Карточка показывает одну цифру; спарклайн за 32 пикселя показывает, тренд это или случайный всплеск. |
| Единые изменения | Везде одна форма: «▲ +1.9% vs Jun 2018» и «▲ +79.7% vs Jul 2017»; п.п. (pp) для доли опозданий, баллы (pts) для оценки. | Меньше форматов, которые надо выучить. |
| Типографика | Один шрифт (Inter с системным запасным; IBM Plex Sans как второй выбор), табличные цифры, числа выровнены вправо, один формат на вид величины (BRL 1.04M, разделители тысяч), тот же шрифт внутри графиков Plotly, почти чёрный текст. | Выровненные цифры сравниваются на глаз; один шрифт выглядит продуманным. |
| Отступы и сетка | Шаг 8 пикселей, широкие поля, ширина содержимого до 1 200 px, на телефоне сетка складывается в колонку. | Пустое место группирует элементы без линий. |
| Воронка столбцами | Горизонтальные серые столбцы, на каждом конверсия шага и число потерянных заказов; самое большое падение акцентным цветом. | Столбцы шагов почти одной длины (потери несколько процентов), поэтому информацию несут подписи, а цвет указывает на главное. |
| Таблицы со встроенными полосками | В колонке GMV светлая полоска под числом (относительно самой большой строки). | Рейтинг виден без отдельного графика. |
| Порядок рассказа | Заголовок и «что это значит», карточки KPI, воронка, динамика, таблицы, подвал с источником, лицензией, окном и пометкой, что требования смоделированы. | Так читает руководитель продаж: что случилось, где течёт, с каких пор, кто. |

## Что я выбрала и чем за это плачу

- Шрифт Inter подгружается с Google Fonts. Без интернета страница берёт системный
  шрифт; цифры не меняются.
- Plotly подгружается с CDN, поэтому два графика требуют интернета.
- Статичное превью PNG (matplotlib) использует ту же палитру и компоновку; шрифт Inter
  или IBM Plex Sans, если установлен, иначе DejaVu Sans, так что начертание букв может
  отличаться от HTML. В таблицах 8 строк вместо 15.
- Пороги подкраски (1 п.п., 0,1 балла) условные, как в спецификации.
- В моей среде нельзя открыть HTML в браузере, поэтому визуально я проверила PNG;
  HTML стоит один раз посмотреть в браузере.
